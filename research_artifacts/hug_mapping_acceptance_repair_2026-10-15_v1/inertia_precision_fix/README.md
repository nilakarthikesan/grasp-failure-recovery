# Source-tensor-preserving object inertia import

This localized importer change converts only a copied, already physically validated full inertia tensor to principal moments and a proper quaternion using NumPy's symmetric eigensolver and17-digit values. It avoids the demonstrated MuJoCo3.3.7 full-tensor diagonalization residual. Original source bytes, content address, mass and intended tensor stay fixed; explicit diagonal inertia/orientation inputs remain unchanged. Existing invalid-source physical validation runs first.

Source and test preimages, proposed bytes, exact applied receipt and patch are retained. The static regression compares the physical tensor instead of an arbitrary principal-frame quaternion. Twenty selected proposed-source tests passed with zero forwards/steps; the parent also ran the applied repository's static object-asset tests with physics APIs blocked (see repository_tests.log and receipt). Spherical, repeated, rotated repeated and general symmetric tensors, unchanged source identity, explicit diagonal frames and invalid original inertias are covered. No saved grasp inference, fit or evaluation data was generated by this patch.

The independently reviewed v2 assembled-scene run is a separate artifact with unchanged numerical criteria. This change alone establishes no native MANO-to-Shadow geometric equivalence or dynamic grasp outcome.
