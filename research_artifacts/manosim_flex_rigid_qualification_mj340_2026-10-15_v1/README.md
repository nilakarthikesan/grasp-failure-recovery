# Separate MuJoCo 3.4.0 rigid flex qualification

Status: SOURCE ONLY; no preparation, engine model, forward or scientific run has been performed for this protocol. This is a new study. The completed failing MuJoCo 3.3.7 report and its independent readback are immutable inputs; their verdicts remain NOT_QUALIFIED.

The twelve synthetic XML models, ordered six probes per model, 12 compilation/12 data/84 explicit-forward caps, 120-second worker and 130-second outer caps, geometry, radii and numerical limits are copied unchanged from the old study. No native MANO/HUG assets, physics integration, task data or training are allowed. Base NumPy remains 2.2.6. MuJoCo3.4.0 is loaded only from the separately installed --no-deps target `runs/manosim_mujoco_3_4_0_runtime_v1`, inserted before scientific imports. Its distribution files and executable are hashed; the base environment is not modified.

The pinned official engine source e55fff5dea6f1d5dd7963ca52eecc41d05ad0922 normalizes inverse-distance element weights by their sum, while the old 3.3.7 source used L2 normalization. This motivates a prospective repeat; it does not establish an empirical fix. Multi-owner translation comparisons still use the original barycentric reference and remain part of the unchanged full six-case-per-radius verdict. They are never silently replaced with inverse-distance expected values.

A separately named RIGID_ONLY verdict checks all four single-owner cases per radius: one triangle and two disconnected triangles, each at identity/nonzero frame. It requires every original contact/geometry/translation/rigid-rotation/gap/frame check for those cases. Its capability helper is `qualified_rigid_radius_policy`, with a new schema; the old full qualification helper is absent. A rigid-only result may coexist with a failed full multi-owner verdict, both reported explicitly. This narrower claim applies only to a locked-articulation snapshot. It does not validate MANO skin deformation, arbitrary poses, physical dynamics, native surface fidelity, collection or training. Zero radius remains undocumented; positive radius remains geometric inflation.

Root must save successful manufactured controls as `controls.json`, prepare `protocol.json`, commit the exact source/declaration, then separately authorize one run. No actual result is predeclared. Use the original venv with `PYTHONPATH` pointing first to the isolated target and `PYTHONDONTWRITEBYTECODE=1` for manufactured wrapper tests. `prepare` and tests perform only file/hash/arithmetic/mock operations. `run` verifies committed source/protocol bytes and runtime before allowing the same finite synthetic engine operations.
