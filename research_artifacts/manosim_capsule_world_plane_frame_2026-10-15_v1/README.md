# Prospective static-plane frame-cache correction

Capsule execution v2 is preserved as HARD_STOP. Its first contact fixture exceeded the unchanged5mm penetration guard; all12 static mapping checks and the first two tracking/gravity fixtures had passed. The failed fixture's XML/early model snapshot had a world plane at `[0,0,-100]` with identity quaternion. Its later model snapshot records the intended nonidentity quaternion, but neither `geom_sameframe` nor actual plane rotation was retained. This note therefore supplies source-backed diagnosis, not direct measurement of the missing flag/readback.

Pinned MuJoCo3.4.0 [`user_model.cc:2577–2590`](https://github.com/google-deepmind/mujoco/blob/3.4.0/src/user/user_model.cc#L2577-L2590) assigns `BODYROT` to a geom with identity local rotation and nonzero translation. [`engine_core_smooth.c:195–198`](https://github.com/google-deepmind/mujoco/blob/3.4.0/src/engine/engine_core_smooth.c#L195-L198) passes that cached flag to [`mj_local2Global`](https://github.com/google-deepmind/mujoco/blob/3.4.0/src/engine/engine_core_util.c#L799-L838). `BODYROT` copies owner-body rotation; `NONE` composes the geom quaternion. A runtime quaternion assignment alone cannot update this cached choice. Enum `NONE=0` is declared in the [pinned header](https://github.com/google-deepmind/mujoco/blob/3.4.0/include/mujoco/mjmodel.h#L357-L363).

The prospective v3 fixture must set the declared plane flag to `NONE`, retain before/after values, and assert/save actual plane position/rotation plus initial capsule-plane tangent geometry after the already-budgeted second forward and before integration. A guard failure must save available contact operands before raising. The library change only fingerprints `geom_sameframe`; it does not move the hand/plane or modify physics thresholds. One manufactured mutation test covers that fingerprint. No native model, FK, contact query or physics call was used for this note or patch. Public source snapshots and complete SHA256 bindings are stored alongside this note.
