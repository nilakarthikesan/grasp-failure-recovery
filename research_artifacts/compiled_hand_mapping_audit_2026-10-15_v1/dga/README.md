# DGA saved pose conversion audit, 15 October 2026

This audit reads the frozen 16-output MultiDex cohort and the two saved component-corrected poses. It performs no inference, optimization, physics stepping, evaluation episodes, labels, or training. The target asset and scientific criteria are unchanged.

`target_cases_v1.json` exports all 18 poses for the shared compiled MuJoCo comparison. Every case carries a 24-joint dictionary, object-from-target-palm/root/forearm transforms, independent source and target XML FK for all links, original status, and input hashes. Fifteen raw domain rejects are retained as diagnostic kinematics only; setting these joint numbers for FK does not make them executable. The two corrected poses retain their prior surface failure and remain unaccepted.

`dga_conversion_audit_v1.json` and `audit_dga_frames.py` independently reconstruct source rotations using symmetric 6D-column orthogonalization and XML FK using SciPy rotations. The provider decoder and mapper agree with these reconstructed frames to maximum matrix component error 6.67e-16. The ledger's five source-limit rejects, ten additional target-limit rejects, and one domain-valid candidate are reproduced. Both corrected wrist values remain exactly unchanged. No DGA provider conversion defect was found by this frame-only check.

DGA's root is the source forearm. The target URDF root is a link named `world`, whose fixed transform precedes its forearm. Target root placement is `object_from_palm @ inverse(target_root_from_palm(q))`. This preserves the actual palm pose without counting wrist FK twice. The export includes both target root and forearm poses to avoid confusing the URDF root with the simulator's floating forearm body. Wrong-root controls produce 14.14 mm or 247.21 mm palm displacement.

`joint_conventions_v1.json` independently distinguishes coordinate choices from geometric differences. Although source and target thumb link frames differ by about 90 degrees and their local joint axis coordinates differ, their spatial thumb joint axes after palm alignment agree within 2.10e-10 rad over the zero pose and all 16 native poses. No thumb sign or permutation correction is justified. The thumb chain's base displacement of 0.08 mm, different joint limits, and source one-box versus target eight-box palm collision declarations are real asset differences. The little-finger spatial joint axis differs by at most 3.11e-5 rad, consistent with the target's rounded fixed frame rotation. These findings do not certify surface equivalence or change earlier failed results.

The common compiled-model comparison is performed separately by the parent harness. This directory contains frame-stage evidence only; it does not claim that the DGA mapping is accepted, that compiled collision geometry matches its declarations, or that a grasp is physically successful.
