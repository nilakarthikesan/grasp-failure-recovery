# Frozen occupied-union diagnostic

This bundle is a static development diagnostic on six existing HUG grasps, each at its original and previously selected pooled Shadow pose. It does not modify the mapper or historical acceptance criteria.

- `protocol.draft.json`, `protocol.json`, `execution_authorization.json`: pre-measurement method, closure and authorization.
- `exposed_classifier.py`, `test_exposed_classifier.py`, manufactured receipts/logs: pure diagnostic and controls.
- `run_diagnostic.py`, `prepare_protocol.py`: bounded source reconstruction and fixed protocol preparation.
- `case_*.json`: all 624 retained row-pose records, including raw distances, bounds, provenance, burial and uncertainty.
- `cohort_8_12_16_20_24_28.json`: case hashes and actual execution counters.
- `summary.json`, `REPORT.md`: saved-output aggregation and scientific limits.

The driver refuses existing outputs. Reproduction requires a separate output directory/version, intact hash-bound source assets and the declared external Python environment. Do not overwrite the immutable results or rerun to choose a preferred outcome.
