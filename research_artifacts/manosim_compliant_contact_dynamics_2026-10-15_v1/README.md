# Compliant common-point contact integration — source only

This is a new numerical model and protocol, separate from stock MuJoCo flex contact and from native MANO physics. It integrates the exact frozen `manosim_articulated_skin_2026-10-15_v1/contact_law.py` kernel using explicit `qfrc_applied` on an analytic 0.2 kg, 10 mm radius, translation-only sphere. Engine contacts, constraints, collisions, actuation, passive/control callbacks, damping and armature are forbidden. The hand point Jacobian is explicitly 3×51 with the first three columns identity; the static object's Jacobian is 3×1 zero. All other 48 synthetic hand coordinates have zero velocity/load. This exercises the selected 51-coordinate force interface without loading a native hand or certifying articulated geometry, physical materials, collection or training.

The fixed constitutive assumptions are k=20000 N/m, c=2√(k·0.2)=126.49110640673517 Ns/m, μ=0.5 and friction regularization speed 0.001 m/s. They are model assumptions, not calibration. Gap is sphere center z minus radius, outward normal +z, and the common application point is the sphere's bottom point in world coordinates. The same point defines the equal/opposite object reaction and torque. For penetration δ>0, Fn=max(0,kδ−c·vn); otherwise Fn=0. Ft=−μFn vt/√(|vt|²+vreg²). No stock contact force is used.

No constitutive parameter, gate or physical outcome informed the change.
