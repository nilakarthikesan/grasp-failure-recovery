# Derived simulated task-outcome dataset, version 1

This portable export contains 1,040 closing histories from the two-geometry
simulation pilot. It is generated data, not the original HUG dataset or an
official benchmark. See [the collection](../../docs/MULTI_SCENE_COLLECTION.md),
[the split/input contract](../../docs/DATA_SPLITS.md) and
[the working paper](../../docs/paper/working_draft.tex).

- `dataset.npz`: 1,040 × 1,440 float32 observable inputs, binary task labels,
  episode IDs and group identities. Open with `allow_pickle=False`.
- `manifest.json`: exact joint/field ordering, timing, label rule, source hashes
  and HUG asset/proposal provenance.
- `splits.json`: 520 training, 260 validation and 260 test attempts; whole
  observation and proposal families stay together.

Inputs contain only measured hand positions, measured velocities and applied
targets through 2.96 s, before lifting. Source identities and final outcomes
are stored separately. No raw HUG/MANO payloads, meshes, model weights, images
or full simulator states are distributed here.

The apple geometry used by the local simulation comes from
[HUG / 1M-HuGs by kevinywu](https://huggingface.co/datasets/kevinywu/1m-hugs),
revision `56ea3f100b1a4ec38bb35e986c0dd14d38977283`, under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
See the manifest and collection guide for exact attribution and transformation
provenance. This export consists of trajectories generated by our controller
and simulator; it is not a redistribution of those source assets.

Both geometries appear in training; validation is cube-only and test is
apple-only. These retrospective development holdouts do not measure unseen
geometry, real-world failure rates or fixed-horizon slip warning performance.
